## Chạy local
npm install
npm run dev

## Build
npm run build

## Deploy Netlify
Import repository vào Netlify, build command `npm run build`, publish directory `dist`.
File `netlify.toml` đã cấu hình sẵn.

## Ghi chú
Dữ liệu đã được embed vào `src/data.js` để website chạy độc lập, không cần upload Excel sau khi deploy.
